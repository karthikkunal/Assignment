# Security policy

QuantumGenie Discovery is a local metadata inventory tool. Use it only on systems and network targets you are authorized to inspect.

## Safe defaults

- API and agent bind to loopback only.
- A fresh shared agent token is generated by the startup script unless explicitly supplied.
- Certificate files are read-only; symlinks are not followed.
- TLS collection records metadata only. It does not capture payloads, decrypt traffic, collect credentials, or collect private keys.
- Password-protected keystores are not opened.

## Reporting a vulnerability

Do not include credentials, private keys, packet payloads, or other sensitive evidence in a public issue. Provide a minimal reproduction and affected version to the repository owner through a private GitHub security advisory.
